# hiring.1005labs.com

Static hiring page + fake ERP portal for the "Our agent found this job in 18 seconds. Can yours?" puzzle.

- `index.html` — landing page with the recorded run.
- `erp/` — the demo ERP. Client-side only, synthetic data, no backend. Login `candidate` / `findme`.
- `assets/` — pixel agents, the recorded run (`dash-run.*`), OG image.

Deployed with GitHub Pages; `CNAME` points the custom domain. Source of truth for copy lives in `~/Desktop/1005 Labs/Hiring/`.
